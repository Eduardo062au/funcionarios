# funcionarios

## O que é?
Sistema que gerencia funcionários de uma empresa.

## Como executar
1. Instale as dependências:
   npm install

2. Execute o projeto:
   npm start

## O que o sistema faz
- Cadastra novos funcionários
- Atualiza o salário de um funcionário
- Consulta as informações de um funcionário

## Testes realizados
- Cadastro de 4 funcionários: Eduardo, Danilo, Gilmar e Antonio
- Atualização do salário do Danilo de R$4000 para R$4500
- Consulta das informações do Danilo
- Tentativa de consultar funcionário inexistente (matrícula 1000)
